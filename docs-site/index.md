# Scribe

**A local desktop companion for following Claude Code sessions and human decisions.**

<Badge type="warning" text="Windows beta · evaluation only" />

The experimental `v0.1.0-beta.2` targets IT evaluation with app/helper `0.1.0-beta.2` and plugin `0.1.1` over stdio. Check the [release page](https://github.com/rexia-intel-automation/scribe/releases/tag/v0.1.0-beta.2) for availability and checksums; an unavailable page means publication is incomplete. It is not an accepted final release. The older beta.1 HTTP pairing is incompatible. See [installation compatibility notes](/installation).

## Follow sessions

See active sessions, recent activity, and waiting decisions in a compact desktop window.

## Decide with context

Review permission requests and answer supported questions without searching for the right terminal.

## Keep data local

Scribe is designed as a local companion. It does not call an AI model or send telemetry.
