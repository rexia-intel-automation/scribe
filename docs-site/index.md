# Scribe

**A local desktop companion for following Claude Code sessions and human decisions.**

<Badge type="warning" text="Windows beta · evaluation only" />

The published `v0.1.0-beta.1` is a Windows prerelease for evaluation by the IT team. It is not a final release. A fresh interactive Claude Code session is still needed to validate native questions and plan approval. Work in open pull requests is not part of this beta.

## Follow sessions

See active sessions, recent activity, and waiting decisions in a compact desktop window.

## Decide with context

Review permission requests and answer supported questions without searching for the right terminal.

## Keep data local

Scribe is designed as a local companion. It does not call an AI model or send telemetry.
