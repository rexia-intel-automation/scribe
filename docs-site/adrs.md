# Architecture decisions

Architecture Decision Records explain why project choices were made. This public site intentionally does not mirror the repository’s complete internal decision, review, or evidence folders.

The current beta’s documented principles are:

- keep event handling and app communication local;
- show only sanitized session summaries;
- leave unsupported or ambiguous decisions in the Claude Code terminal;
- require an explicit human gesture and never convert timeout into approval;
- preserve the known limits of each beta instead of presenting in-progress work as released behavior.

The source repository contains the authoritative engineering records. Only records explicitly selected and reviewed for public release should be added here.
