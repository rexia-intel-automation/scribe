# Decisões de arquitetura

Registros de Decisão de Arquitetura explicam os motivos de escolhas do projeto. Este site público não espelha as pastas internas completas de decisões, revisões ou evidências do repositório.

Os princípios documentados da beta atual são:

- manter o processamento de eventos e a comunicação do app locais;
- exibir apenas resumos higienizados das sessões;
- deixar decisões incompatíveis ou ambíguas para o terminal do Claude Code;
- exigir um gesto humano explícito e nunca converter timeout em aprovação;
- preservar os limites conhecidos de cada beta, sem apresentar trabalho em andamento como funcionalidade publicada.

O repositório é a fonte dos registros de engenharia. Só registros explicitamente selecionados e revisados para publicação devem ser acrescentados aqui.
