# Histórico de versões

Esta página registra somente versões publicadas. Mudanças em desenvolvimento ou em pull requests abertas não fazem parte de uma release até serem incluídas em uma versão marcada.

## v0.1.0-beta.1

Pré-lançamento Windows para avaliação da TI. Oferece um app local para acompanhar sessões, cartões de decisão de permissões, status de sessão e um caminho de configuração do plugin no Windows. Ainda não é a versão final v0.1. O aceite de perguntas nativas e aprovação de planos numa sessão interativa nova continua pendente.

Consulte os [arquivos e notas da beta](https://github.com/rexia-intel-automation/scribe/releases/tag/v0.1.0-beta.1). Os arquivos exatos e os checksums publicados com a release são a fonte autoritativa para aquele build.
