# Primeiros passos

Depois de instalar a beta Windows e configurar o plugin:

1. Feche as sessões existentes do Claude Code e inicie uma sessão interativa nova com `claude`.
2. Mantenha o Scribe aberto. Inicie trabalho em mais de um projeto para ver as sessões aparecerem.
3. Quando surgir um cartão de permissão, confira o alvo visível antes de escolher **Permitir uma vez** ou **Negar**. Alvos ocultos ou ambíguos devem ser respondidos no terminal.
4. Complete o roteiro de teste da versão beta. Registre as versões do Claude Code e do Windows e a etapa exata que falhou.

A configuração do plugin para o usuário é separada da instalação do app. Executar o script novamente reutiliza a conexão existente; não copie tokens de conexão para relatos. `claude -p` não é o caminho de aceite para perguntas interativas AskUserQuestion.
